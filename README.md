# Student Finance Governance

A Python 3.10 menu-based mini project based on the supplied project report.

## Modules
- User login
- Student details management
- Fee management (college, hostel and mess fees)
- Payment tracking and payment history
- Other expenses
- Student-wise and overall financial reports

## Requirements
- Python 3.10 or later
- No external Python packages required

## Run the project
1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run:

   ```bash
   python main.py
   ```

## Demo login
- Username: `admin`
- Password: `1234`

## Data storage
Student and payment records are saved in `data/finance_records.json`.
Keep this file if you want to retain your records. The application creates/updates it automatically.

## Notes
This is an academic demonstration project. The demo credentials are hard-coded for simplicity and should be replaced with secure authentication before real institutional use. Payments are recorded as entries; this project does not connect to a real payment gateway.
